The grid is the first thing students at the Bauhaus learned to break.

Not because the grid is wrong, but because you cannot break what you do not understand. Josef Müller-Brockmann spent decades evangelizing the grid as a moral system — **a structure that communicates order, clarity, and intent**.

## the grid as a moral system

There is something almost ethical about alignment. When elements share a baseline, they imply relationship. When they don't, the absence of alignment must carry its own weight — it must be intentional.

Modern UI design has largely abandoned this principle. We reach for frameworks that produce acceptable layouts automatically, and in doing so we lose the opportunity to *decide*.

## deciding

Every spacing value is a decision. Every type size is a decision. Every column break is a decision. The grid does not make these decisions for you — it gives you a vocabulary in which to make them coherently.

When I build a layout today, I start with a unit. Usually `8px`. Everything — margins, padding, type size, line height — is a multiple of that unit. This creates a silent rhythm that the eye feels even when the mind doesn't consciously register it.

That is the goal: **felt coherence**.
