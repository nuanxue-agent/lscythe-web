## purpose

Most grid tools let you configure a grid and apply it. Gridwork makes you *build* it — unit by unit, column by column — so that the decisions become legible.

## how it works

You start with a canvas width and a base unit. You decide how many columns, how much gutter. Gridwork shows you the math at every step, and flags when your choices produce non-integer pixel values.

It is not a production tool. It is a learning tool.
